# سایت تیم — راهنمای راه‌اندازی رایگان با GitHub Pages

## ۱. بالا آوردن سایت (رایگان، بدون هزینه)

1. یک ریپازیتوری جدید در گیت‌هاب بسازید (مثلا `team-site`) — می‌تواند public یا private باشد؛ اگر private باشد باید پلن Pro گیت‌هاب داشته باشید تا Pages روی آن فعال شود، پس ساده‌ترین حالت **public** است.
2. تمام فایل‌های همین پوشه (`index.html`, `css/`, `js/`, `admin/`, `data.json`) را داخل ریشه‌ی همان ریپازیتوری آپلود کنید (می‌توانید مستقیم در وب گیت‌هاب با "Add file → Upload files" این کار را بکنید، نیازی به خط فرمان نیست).
3. در ریپازیتوری بروید به: **Settings → Pages**.
4. زیر «Build and deployment» گزینه‌ی Source را روی **Deploy from a branch** بگذارید، شاخه‌ی `main` و پوشه‌ی `/ (root)` را انتخاب کنید و Save بزنید.
5. بعد از حدود ۱ تا ۲ دقیقه، آدرس سایت شما این شکلی می‌شود:
   `https://<نام-کاربری-شما>.github.io/<نام-ریپازیتوری>/`
6. پنل مدیریت هم در آدرس زیر در دسترس است:
   `https://<نام-کاربری-شما>.github.io/<نام-ریپازیتوری>/admin/`

اگر بعدا دامنه‌ی شخصی گرفتید، می‌توانید از همان بخش Settings → Pages فیلد Custom domain را پر کنید.

## ۲. ساخت توکن گیت‌هاب برای پنل مدیریت

پنل مدیریت برای ذخیره‌ی تغییرات (اضافه/حذف پروژه، عضو تیم و ...) مستقیم روی فایل `data.json` در همین ریپازیتوری commit می‌زند، پس یک توکن دسترسی لازم دارد:

1. به آدرس بروید: `github.com/settings/tokens?type=beta` (Fine-grained tokens)
2. **Generate new token** را بزنید.
3. زیر **Repository access** فقط همین یک ریپازیتوری (`team-site`) را انتخاب کنید — نه همه‌ی ریپوها.
4. زیر **Permissions → Repository permissions**، مقابل **Contents** روی **Read and write** بگذارید.
5. توکن را بسازید و آن را کپی کنید (فقط یک‌بار نشان داده می‌شود).

## ۳. اولین ورود به پنل مدیریت

1. آدرس `/admin/` سایت را باز کنید.
2. چون اولین بار است، فرم «راه‌اندازی اولیه» را می‌بینید: نام کاربری گیت‌هاب، نام ریپازیتوری، شاخه (`main`)، توکنی که در مرحله‌ی قبل ساختید، و یک **رمز عبور دلخواه** برای همین پنل را وارد کنید.
3. بعد از ثبت، اطلاعات به‌صورت رمزنگاری‌شده (AES) فقط در همان مرورگر/دستگاه ذخیره می‌شود — نه جای دیگری.
4. دفعات بعد که وارد `/admin/` می‌شوید، فقط همان رمز عبور را وارد می‌کنید و مستقیم به بخش ویرایش می‌روید، بدون نیاز به وارد کردن دوباره‌ی توکن.
5. اگر رمز را فراموش کردید یا خواستید ریپازیتوری/توکن را عوض کنید، در همان صفحه گزینه‌ی «فراموشی رمز / تغییر مخزن» را بزنید.

## ۴. چیزهایی که از پنل بدون کدنویسی قابل مدیریت‌اند

- نام تیم و شعار سایت
- عنوان تک‌تک بخش‌ها (مهارت‌ها، تیم، پروژه‌ها، تماس) و متن راهنمای چرخش پروژه‌ها
- افزودن/حذف/ویرایش مهارت‌ها و درصدشان
- افزودن/حذف/ویرایش اعضای تیم (نام، سمت، بیوگرافی، لینک‌ها)
- افزودن/حذف/ویرایش پروژه‌ها (عنوان، دسته CV/LLM/Agent/Dev، توضیح، لینک) — که خودکار در نمای سه‌بعدی چرخان ظاهر می‌شوند
- افزودن/حذف/ویرایش راه‌های تماس (ایمیل، تلگرام، هرچیز دیگری)

## نکته‌ی امنیتی

- مسیر `/admin/` را برای کسی که نباید دسترسی داشته باشد لینک نکنید (این یک قفل رمز محلی است، نه یک سیستم لاگین سمت سرور).
- توکن گیت‌هاب را فقط با دسترسی Read/Write روی همین یک ریپو بسازید، نه با دسترسی کامل به همه‌ی حساب‌تان.
- اگر توکن لو رفت، از `github.com/settings/tokens` می‌توانید فورا آن را Revoke کنید و یک توکن جدید بسازید (و دوباره در پنل «فراموشی رمز» زده و از نو وارد کنید).
